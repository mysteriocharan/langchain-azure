# Fulfillment Operations Review

The weekly review covers the Seattle, Phoenix, and Dallas fulfillment centers.

Flag a condition when any of these thresholds is met:

- Late-order rate is greater than 5 percent.
- Return rate is greater than 3 percent.
- Absolute inventory variance is greater than 2 percent.
- A high-severity incident remains open.

Recommend actions that are directly supported by the supplied metrics and incidents.
Do not infer causes that are not documented in the source files.
